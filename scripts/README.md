# Experiments 
This forder cantains the scripts to run the experiments.
To reproduce the full set of the experiments follow [this guide](../README.md).

### Folder content

- `check_if_deps_embedded.sh` checks if all the dependency in a jar are embedded.
- `check_tests_run.sh` checks if the test outcome remains the same before and after the embedding.
- `clean.sh` cleans the artifacts generated by Classport, see --help for flags.
- `compute_build_overhead.sh` computes the difference in time between build with and without embedding.
- `embed_with_copy.sh` embeds multimodule projects
- `embed.sh` embeds projects
- `introspect_*.sh` runs the introspector
- `post_process_local_repo.sh` merges the classport-files repos
